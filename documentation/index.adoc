== What is MCP?

The https://modelcontextprotocol.io/[Model Context Protocol] (MCP) is an open protocol that enables AI assistants to interact with external systems.
{ProductName} implements this protocol to provide AI assistants with access to Kubernetes-based streaming infrastructure.
